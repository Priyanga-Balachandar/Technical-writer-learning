# Installation Procedure

## 1. Purpose

This procedure describes the steps required to install the system.

## 2. Prerequisites

Before starting the installation, verify the following:

- Required hardware is available.
- Required cables are available.
- Power supply is available.
- Installation environment meets the specified requirements.

> [!WARNING]
> Ensure that the power supply is switched OFF before connecting or disconnecting hardware.

## 3. Installation Steps

1. Inspect all components for physical damage.
2. Position the equipment at the designated location.
3. Connect the required cables.
4. Connect the power supply.
5. Switch ON the system.
6. Verify the system status indicators.

## 4. Verification

Verify the following:

- [ ] Power indicator is ON
- [ ] Communication link is established
- [ ] System status is normal
- [ ] Required output is available
